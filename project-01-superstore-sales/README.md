# Project 01 - Superstore Sales Analysis

## Overview

Data analysis project based on the Superstore dataset.

The project combines SQL and Excel to analyze sales, profit, margins, customers, products, regions, and data quality issues.

## Objectives

- Analyze sales and profitability.
- Identify low-margin and loss-making areas.
- Evaluate categories, sub-categories, regions, and customer segments.
- Detect and investigate data quality problems.
- Analyze duplicate records and their impact on business metrics.
- Document security and access-control case studies using synthetic data.

## Tools

- SQL
- SQLite
- Excel
- GitHub

## Case Studies

### 1. Data Quality

Simulated missing and inconsistent values were detected, investigated, corrected, and validated using SQL.

### 2. Duplicate Records

Simulated duplicate sales records were identified and their impact on total sales and profit was measured.

### 3. Security and Data Access

Synthetic security cases were analyzed, including:

- Guardrail input validation
- PII detection and redaction
- Customer data access auditing
- Suspicious access patterns
